# Design canvas sources

These are the artboard sources for the Toto Screener Redesign canvas — the
editable design artifact at
https://claude.ai/code/artifact/1eb6ec62-f46a-46d1-a0a8-ebefb32c57ed

Each `.dc.html` file is one artboard; `canvas.json` lays them out. To update
the canvas from any machine, edit these files in a Claude Code session and ask
it to re-seed and republish with the `/design` skill (same artifact URL,
contract 0.1.31, 🖌️ favicon). The seeded output file is not committed — it is
regenerated from these sources every time.

Keep these in sync with the shipped UI in `web/`.
