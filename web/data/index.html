    Reading these tables

    • Sizes 1–8 are published. Larger households follow HUD's rule — add 8% of the 4-person limit per extra person — which the screener applies automatically.
    • USDA publishes in brackets — one figure for 1–4 persons, another for 5–8 — so those cells repeat by design.
    • SMI and FPG are not county figures. State median income is statewide; poverty guidelines are national. They appear under every county because programs in every county use them.
    • HERA Special applies only to LIHTC buildings placed in service before 2009. No program is routed to it by default.
