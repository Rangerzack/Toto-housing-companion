# Results redesign source

`Toto Housing Companion Redesign.dc.html` is the design-canvas export this
redesign was built from — two turns (light and dark) covering desktop and
mobile results, the programme detail modal, and the housing plan.

Implemented: the colour system, the results page (headline, needs summary,
crisis strip, best-next-steps cards, rentals-within-budget cards, compact
"more programs" rows) and the detail dialog.

Not yet implemented: the **housing plan** board (1e/2e) — a checklist with
tickable next steps, "add your own step", and saved rentals alongside saved
programmes. Saved rentals need the plan to store listing snapshots rather than
programme ids, which is why rental cards carry no save control yet.
